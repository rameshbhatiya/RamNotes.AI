## 📌 About The Project

**RamNotes AI** is an all-in-one educational assistant web application designed to help NCERT students across Class 6 to Class 12 with AI-generated chapter notes, textbook solutions, instant doubt resolution, and dynamic chapter-wise quizzes.

---

## ✨ Key Features

- **📚 NCERT Notes Engine**: Generates comprehensive notes, key formulas, and important questions for any chapter.
- **💡 Step-by-Step Solutions**: Solves textbook exercise questions with detailed explanations.
- **🤖 AI Doubt Solver**: Instant answers and step-by-step guidance for custom user questions.
- **🎮 Dynamic Quiz Module**: Class and Subject-wise 20-mark interactive quizzes with real-time score tracking and visual feedback.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+), FontAwesome Icons
- **Backend**: Python (FastAPI / Render Engine)
- **Deployment**: [Render.com](https://tes-ai.onrender.com)
